# Group 16 Inception report downloads

Download the LaTeX source and the supporting charts and evidence from the two ZIP files in this directory. Each outer ZIP uses AES-256. Open it in 7-Zip with the password supplied separately by the team, then extract the original ZIP inside.

For revisions, update the encrypted archive under the same filename on the `course-report-downloads` branch. Branch links follow the latest version. A link containing a commit SHA identifies a specific revision. Keep the password with the team.
